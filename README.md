# 👾 Space Invaders

Una recreación del clásico juego arcade **Space Invaders**, desarrollado íntegramente en **Java**.

## ⚙️ Arquitectura del Proyecto

El código está estructurado siguiendo el patrón de diseño **MVC (Modelo-Vista-Controlador)**. Esta decisión nos permitió separar claramente las responsabilidades dentro del juego:

* **Modelo:** Maneja toda la lógica del juego.
* **Vista:** Se encarga exclusivamente de la interfaz gráfica.
* **Controlador:** Actúa como intermediario.

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** Java
* **Entorno de Desarrollo (IDE):** Eclipse
* **Control de Versiones:** Git & GitHub
